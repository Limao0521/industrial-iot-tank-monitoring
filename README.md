# Industrial IoT – Chemical Tank Level Monitoring

Proyecto RA2.3 de monitoreo del nivel de un tanque químico mediante tres sensores digitales, CODESYS con HMI y OpenPLC con ESP32. Documenta los cuatro estados válidos, la detección de combinaciones incoherentes y el control de inicio/parada.

La documentación incluye tabla de verdad, ecuaciones booleanas, Ladder, HMI, direcciones IEC, GPIO confirmados, fotografía del prototipo, matrices de pruebas, resultados, conclusiones y referencias oficiales. STOP corresponde a GPIO 16; SystemActive, a GPIO 17. El mapa de señales describe las asignaciones confirmadas; no sustituye un esquema eléctrico detallado.

El video se entregará **como archivo directamente en Teams**. Los resultados de simulación y hardware documentados son los reportados por el autor durante las pruebas del proyecto.
